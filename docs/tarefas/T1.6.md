# T1.6 — Texts of the daily return (EN + ptBR) and the Market card

**Owner:** Codex · **Reviewer:** Claude · **Sprint:** 1 · **Estimate:** 1.5 h · **Branch:** `codex/T1.6-texts`
**Start after T1.5 is merged** (Claude: the "While you were away" card and the order of the day on the Market screen).

## Why

T1.5 builds the screens with English texts that work but are first drafts, and ptBR copies marked to be written. This
task makes every text of the daily return right in both languages, and tells the player about it.

## What to do

1. In `Locales.lua`, every key added by T1.3/T1.4/T1.5 (they start with `away`, `daily` or `streak`; search for them):
   - **English:** review; short, plain, friendly; the same tone as the rest of the file (`tut_*`, `head*`).
   - **ptBR:** write it (T1.5 leaves the English text in the ptBR table as a placeholder, with the comment `-- TODO ptBR`).
     Brazilian Portuguese, informal "você", the words the game already uses: "Celeiro", "Mercado", "encomenda",
     "sequência", "canteiro".
   - Plural pairs: when T1.5 has `...One` / `...Many` keys, both languages get both.
2. The Market card (`tut_market1..3`): rewrite the three lines so one of them tells about the order of the day and the
   streak. Still three lines, each must fit one line of the card (about 70 characters).
3. **What's new** (`News.lua`, entry 1 = `2.0.0-alpha1`): add the lines `news1_2`, `news1_3`, ... in both languages, one
   per thing the player will notice in alpha 1 (the card when coming back with "Collect all", the order of the day, the
   streak and its prizes). Player words, one sentence each.
4. Remove every `-- TODO ptBR` left.

- Keys: do not rename or delete keys; the code reads them by name.
