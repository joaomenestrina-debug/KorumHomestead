# T0.9 — `KH.Day()`: the day of the player, for everything that is daily

**Owner:** Codex · **Reviewer:** Claude · **Sprint:** 0 · **Estimate:** 1 h · **Branch:** `codex/T0.9-day`
Can run at the same time as T0.6 (it only touches `Core.lua` and the tests).

## Why

The 2.0 has a daily order with a streak of days (sprint 1), seasons (sprint 5) and other things that turn over "at
midnight". They all need one function that says which day it is, in the player's own time, that the tests can move.

## What to do

In `Core.lua`, next to `KH.Now()`:

```lua
-- The player's local day, as a number that grows by one at each local midnight (days since 1970-01-01, local time).
function KH.Day(at) ... end

-- Seconds until the next local midnight, for "the next order in 3h 12m".
function KH.UntilNextDay(at) ... end
```

- `at` is optional and defaults to `KH.Now()`.
- Use `date("*t", at)` to find the local date and build the day number from year, month and day, so it is right on days
  with a daylight saving change (23 h or 25 h long). Do not divide `time()` by 86400: that is the UTC day, not the
  player's.
- No other file changes; nothing uses these functions yet.

## Tests (new, in `tests/test_homestead.py` or a new `tests/test_day.py`)

The client mock gives `time()` from `NOW`. Add a way for the test to give `date` too if the mock lacks it (Lua's own
`os.date` is fine in the test state).

- [ ] Two moments one minute apart before and after local midnight give days that differ by 1.
- [ ] Two moments 23 h apart inside the same local day give the same day.
- [ ] `KH.UntilNextDay` at 23:00 local is 3,600 (± 1); at 00:00:00 it is 86,400.
- [ ] Across a daylight saving change (set `TZ` for the test process, e.g. `America/Sao_Paulo` in an old year that had
      DST, or `Europe/Berlin`), the day still advances exactly once per local midnight. If the time zone cannot be set on
      the machine running the tests, mark that test as skipped with the reason.

## Done when

- [ ] The tests above pass, and all old tests pass unchanged.
- [ ] Both functions have a comment saying what they return and in which time.
