# T0.8 — `Balance.lua`: every number of the game in one place

**Owner:** Codex · **Reviewer:** Claude · **Sprint:** 0 · **Estimate:** 2 h · **Branch:** `codex/T0.8-balance`
**Start after T0.6 is merged** (it touches the same files).

## Why

The 2.0 needs a round of tuning (how many coins an hour each activity gives). Today the numbers of the game are spread
over `Data.lua`, `Farm.lua`, `Village.lua` and `Works.lua`. They must live in one file, so tuning is changing a table,
not hunting through the code.

## What to do

1. Create `Balance.lua`, loaded right after `Locales.lua` in `KorumHomestead.toc`. It defines `KH.Balance` (call it `B`
   in the other files) with these tables, **moved as they are, same values**:

   | From | What |
   |---|---|
   | `Data.lua` | `PLANTS` (the 13 herbs: level, time, seed cost, price, xp, harvest), `MAX_LEVEL`, `MAX_PLOTS`, `ORDER_SLOTS`, the xp curve of `XPToNext`, the extra harvest of `Yield` (one more every 6 levels) |
   | `Farm.lua` | the numbers of an order (`2 + Rand(5) + level/5`, the `1.6` of the pay, the `/2` of the xp, the range of plants `level - 8`), the starting coins if any |
   | `Village.lua` | `MAX_LEVEL`, `NEEDS_HALL`, `GOODS` (sell prices and `perHour`), `COST`, `TIME`, `ORE`, the barn size (`40 *` level), the market bonus (`0.04` a level) |
   | `Works.lua` | the workshop `RECIPES` (level, time, inputs), the Inn `MISSIONS`, the follower names stay where they are, `I.MAX`, the follower pay bonus per level and the missions per level |
   | `Core.lua` | the starting coins (`coins = 40`) and plots (`nplots = 2`) of the defaults |

2. The old places keep working for the code that reads them: `D.PLANTS`, `V.COST`, `W.RECIPES`, etc. become references to
   the tables in `KH.Balance` (`D.PLANTS = B.PLANTS`), so the rest of the code and the tests do not change.

3. Each table in `Balance.lua` gets a one-line comment saying what its numbers are (unit: seconds, coins, per hour...).

## Must not change

- Any value. Same numbers, same behaviour. Item ids and English fallback names of the herbs stay together with the numbers
  (they are one row each today).
- Texts, screens, saved data.

## Done when

- [ ] `python -m pytest tests -q` passes with **no test changed**.
- [ ] A search for numeric literals in `Data.lua`, `Farm.lua`, `Village.lua`, `Works.lua` finds no number of balance left
      (indexes, sizes of the screen and `0`/`1` are fine). List in the pull request anything you were unsure was "balance".
- [ ] `Balance.lua` reads top to bottom as the rules of the game: herbs, orders, buildings, goods, workshop, inn.
