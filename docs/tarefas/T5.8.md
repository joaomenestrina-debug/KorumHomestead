# T5.8 — Review of the new texts (English and Portuguese)

**Owner:** Codex (texts only) · **Reviewer:** Claude · **Approves:** the owner · **Branch:** `codex/T5.8-texts`, cut from
`origin/claude/masmorras` (not from `main`) · **Pull request into:** `claude/masmorras`

## Why

The branch `claude/masmorras` holds the dungeons and followers of versions 2.2 and 2.3 (sprints S3 to S5) and the
changes the owner asked while testing it. It brought **542 texts** that are new or changed since the 2.1.0 Release, in
English and in Brazilian Portuguese. A tool already checks that every text fits its place on the screen; nobody has read
them as a player yet. They go out together in the alpha `v2.2.0-alpha1` once this review is merged.

The list, grouped by the prefix of the key, with both languages side by side: **[T5.8-textos.md](T5.8-textos.md)**.
Read the texts there; change them in **`Locales.lua`** (the list is generated, do not edit it).

## What to look for

1. **Natural language.** Portuguese of Brazil as a player writes it; English as a native player writes it. Short.
   Plain words over game jargon where both work. No em dash (—) in sentences: use a comma, a colon or two sentences.
2. **The same thing has the same name everywhere** (in both languages): follower / seguidor, dungeon / masmorra,
   raid / raide, call / chamado, room / quarto, Lodging / Alojamento, insignia / insígnia, Merit / Mérito,
   Epic / Épico, Rare / Raro, Legendary / Lendário, Mastery / Maestria, combo, trophy / troféu, Barn / Celeiro,
   Workshop / Oficina, Inn / Estalagem, Mine / Mina, Pond / Lagoa. If a key uses a different word, align it.
3. **The two languages say the same thing.** A Portuguese text must not add or drop a fact of the English one.
4. **Names of WoW Forever** (places, peoples, items, dungeons) follow the game: check
   [historia-forever.md](../historia-forever.md) and, for anything not there, the Forever's Wowhead in Portuguese,
   https://www.wowhead.com/forever/pt. Do not invent lore: a text may only cite a place, people or conflict that is in
   `historia-forever.md`.
5. **The followers' names stay** (Mira, Tobin, Elda, Garrick, Sela, Bram and the twelve of A8). Their one-line
   descriptions (`fcl_`), titles (`ttl_`) and origins (`from_`) may be improved.

## Rules of the file (a mistake here breaks the game)

- Change only the **values**, never the keys. Keep every key in both `L.enUS` and `L.ptBR`.
- Keep every format code exactly: `%s`, `%d`, `%.1f`. A literal percent sign in a text that has codes is written `%%`
  (`"+10%% chance"`); `tests/test_formatos.py` fails otherwise.
- Keep the colour codes `|cffxxxxxx ... |r` and the line break `\n` where they are.
- Do not make a text much longer than it is: the window has fixed places. After your changes run
  `python ferramentas/conferir_textos.py` (a few minutes): it must say **`0 problema(s)`**. If a text you improved does
  not fit, shorten it.
- Do not change any other file, except `docs/CONTEXTO.md` (sections 1 and 2: T5.8 done).
