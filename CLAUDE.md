# Korum Homestead

Start every session by reading **[docs/conhecimento.md](docs/conhecimento.md)** (the knowledge base: what exists, the
rules, the characters and the list of what is missing, from which the schedule is made) and then
**[docs/CONTEXTO.md](docs/CONTEXTO.md)**: where the project is, what to do now, the
decisions already taken and the map of the code. Keep its sections 1 and 2 up to date in the same commit that changes the
state of a task.

The rules of the code and of the project are in **[AGENTS.md](AGENTS.md)**; they apply to Claude too. In short: independent
addon, Lua 5.1 on WoW Forever, every text in `Locales.lua` (EN + ptBR), item icons from the game, saves never lose data,
public commits signed as `Korum` with no `Co-Authored-By` line and no mention of AI.

Codex may be working in this same folder on a `codex/...` branch: check `git branch --show-current` and `git status`
before committing, and never `git add -A` over files you did not write.

Talk to the project owner in Brazilian Portuguese.
